Simuladores, guia prático, dados com fonte e notícias do dia sobre dívidas, juros, golpes, benefícios
e preços — num site leve, acessível e sem anúncios.

## Como funciona

### Notícias automáticas

Todo dia às 7h (Brasília) o workflow [`noticias.yml`](.github/workflows/noticias.yml) roda
[`scripts/atualizar_noticias.py`](scripts/atualizar_noticias.py), que:

1. lê os feeds RSS da Agência Brasil, do g1, do InfoMoney e uma busca do Google Notícias;
2. mantém só manchetes de veículos conhecidos que casam com um tema (dívidas, golpes, investir,
   renda, preços) e descarta macroeconomia, empresas e exterior;
3. remove repetidas, guarda os últimos 14 dias em [`dados/noticias.json`](dados/noticias.json) e faz
   commit se houver novidade.

O GitHub Pages republica o site sozinho depois do commit. Para rodar na hora: aba **Actions** →
**Atualizar notícias** → **Run workflow**. Só título, fonte, data e link são guardados; o texto fica
no site de cada veículo.

### Tecnologias

- HTML5, CSS3 e JavaScript puros. Sem frameworks, sem dependências, sem build.
- Uma folha de estilo, [`css/estilo.css`](css/estilo.css), mobile-first, com a paleta em variáveis no `:root`.
- JavaScript só para o menu do celular, o carrossel, os simuladores, as notícias e a animação das
  barras. Sem JavaScript, o conteúdo continua acessível.
- Nenhum dado digitado nos simuladores sai do navegador. Sem cookies e sem rastreadores.

## Rodar localmente

```bash
git clone https://github.com/YagoXavier10/cada-real.git
cd cada-real
python3 -m http.server 8000
```

Acesse http://localhost:8000. Para atualizar as notícias na sua máquina:
`python3 scripts/atualizar_noticias.py`.

## Contribuir

1. Rode `git pull` antes de começar — o robô de notícias faz commits todo dia.
2. Edite, teste localmente e valide o HTML no [validador do W3C](https://validator.w3.org/nu/).
3. `git add -A && git commit -m "descreva a mudança" && git push`

Encontrou um erro ou uma barreira de acessibilidade? [Abra uma issue](https://github.com/YagoXavier10/cada-real/issues).
